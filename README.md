# For bhaiiiii ♡ — apology scrapbook website

A soft, emotional, mobile-friendly static website made with plain HTML, CSS and JavaScript.

## Folder structure

```text
bhaiiiii-apology-website/
├── index.html
├── style.css
├── script.js
└── images/
    ├── bhai1.jpg
    ├── bhai2.jpg
    ├── bhai3.jpg
    ├── bhai4.jpg
    ├── bhai5.jpg
    ├── bhai6.jpg
    ├── bhai7.jpg
    └── bhai8.jpg
```

## Add your photos

Put your eight pictures in the `images` folder and name them `bhai1` through `bhai8`.
The code currently expects `.jpg`. If a photo is `.png`, `.jpeg`, or `.webp`, change that photo's
`src` and `data-full` paths in `index.html` to the exact extension. Filenames are case-sensitive
after publishing.

## Run locally in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension (Extensions icon → search “Live Server”).
3. Right-click `index.html` → **Open with Live Server**.
4. Test the envelope, each photo, the lightbox close button, and the hug button.

You can also open `index.html` directly in a browser, but Live Server is more convenient.

## Publish free with GitHub Pages

1. Sign in at https://github.com/ and create a **public** repository, e.g. `for-bhaiiiii`.
2. Upload `index.html`, `style.css`, `script.js`, and the whole `images` folder.
3. Open repository **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait a few minutes for the Pages URL to appear. It will look like:
   `https://YOUR-USERNAME.github.io/for-bhaiiiii/`

Whenever you change a file, upload/commit the updated file(s) to the same repository.

## Personalize before sharing

The letter is written in Hinglish and doesn't pressure him to reply. You can change the photo captions
to your own inside jokes or real memories. The captions are editable in `index.html`.

Privacy note: a public GitHub Pages site and public repository can be viewed by other people.
Only upload photos you're comfortable sharing.
